# 🍷🔥 PÚA Brasa y Vino | Sitio Web Luxury Multi-Sección

Sitio web oficial de **PÚA Brasa y Vino**, diseñado con una estética **Ultra Luxury Black**, integración directa de reservas por **WhatsApp**, menú oficial interactivo con precios reales y la ficha oficial de **Google Maps**.

---

## 🌟 Características Principales

1. **Estética Ultra Luxury Black**:
   - Fondo negro obsidiana (`#070709`), destellos de oro champán (`#D4AF37`), luces de fuego de brasa (`#FF6B00`) y acentos de rojo vino borgoña (`#800020`).
   - Tipografía Serif de Alta Costura (*Cinzel / Cormorant Garamond*) + Sans Moderna (*Montserrat*).
   - Efectos de cristal oscurecido (*Glassmorphism*), bordes dorados radiantes y micro-animaciones.

2. **6 Secciones Independientes**:
   - **Inicio**: Experiencia cinematográfica con video hero, pilares de excelencia y platillos destacados.
   - **Menú**: Carta interactiva completa (Entradas, Cortes Prime, Hamburguesas, Tacos, Mixología de Autor, Cava de Vinos, Destilados y Postres) con buscador y precios en MXN.
   - **Servicios**: Eventos corporativos, banquetes, catas maridaje con sommelier y formulario de cotización.
   - **Nosotros**: Historia, filosofía del carbón, cava y galería de fotos/videos.
   - **Contacto**: Integración oficial con la ficha de [Google Maps](https://maps.app.goo.gl/ToxSAbb1hKC4XXQAA), horarios y atención.
   - **Reservas**: Motor interactivo de reservación con selección de zona (*Terraza*, *Salón Principal*, *Cava VIP*) y derivación a **WhatsApp**.

3. **Integración con WhatsApp**:
   - Generación automática de mensaje estructurado para confirmación prioritaria e inmediata de mesa o cotización de eventos.

## 🛠️ Tecnologías Utilizadas

- **React 18**
- **Vite 5** (Servidor ultra rápido y compilación optimizada)
- **Lucide React** (Iconografía vectorial luxury)
- **Tailwind CSS & CSS3 Custom Design System**

## 🚀 Instalación y Ejecución Local

```bash
# 1. Clonar o abrir la carpeta del proyecto
cd "PUA BRASA Y VINO"

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev
```

Abre tu navegador en `http://localhost:3000`.

## ⚡ Paso a Paso: Desplegar en Vercel

### Opción A: Desde la Plataforma Vercel (Recomendado)
1. Inicia sesión en [Vercel.com](https://vercel.com).
2. Haz clic en **"Add New"** -> **"Project"**.
3. Importa tu repositorio de GitHub `pua-brasa-y-vino`.
4. En **Framework Preset**, Vercel detectará automáticamente **Vite**.
5. Haz clic en **"Deploy"**. ¡Listo en menos de 1 minuto!

### Opción B: Desde la Terminal (Vercel CLI)
```bash
# 1. Instalar Vercel CLI si no lo tienes
npm install -g vercel

# 2. Desplegar
vercel
```
